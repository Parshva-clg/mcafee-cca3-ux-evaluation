# Survey data status

The CSV files are entirely synthetic demonstration data generated at the project owner's request. They are not Google Form responses, participant measurements, or evidence that the redesign improved UX. Synthetic cases SYN01–SYN05 are unrelated to P1–P5.

The 18 parameter names are provisional author-defined labels, not verified official Google Form wording. Scale assumption: 1 = very poor, 2 = poor, 3 = neutral, 4 = good, 5 = excellent; higher is favourable for every item. This scale is not verified against the official form.

Generator: Python random.Random with seed 20261025. For each of 18 parameters and five synthetic cases, original is sampled from [2,3,3,4]; prototype is original plus a draw from [-1,0,1,1,2], clipped to 1–5. This intentionally improvement-leaning simulation illustrates calculations only. There are 90 paired rows and 180 ratings. Summary means use five synthetic cases per item; difference = prototype minus original. No significance tests or real-world effect claims are warranted.

No authentic survey response export or previous practical files were provided. Replace demonstration data with genuine paired responses and verify the actual question labels and scale before quantitative validation. Do not submit these CSVs as real responses or upload them to the live survey.
